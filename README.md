# CA Sahab – Co-Pilot Birthday Dashboard ✈️🎂

A single-page aviation-style birthday dashboard for the best co-pilot ever.

## Quick Start

1. Open `index.html` in a browser – that's it!
2. Or run a local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit http://localhost:8000

## Deploy to GitHub Pages

1. Create a new repo on GitHub (e.g. `co-pilot-birthday`)
2. Push this folder:
   ```bash
   cd co-pilot-birthday-dashboard
   git init
   git add .
   git commit -m "Birthday dashboard"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/co-pilot-birthday.git
   git push -u origin main
   ```
3. In repo **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** / **root**
4. Your site will be at: `https://YOUR_USERNAME.github.io/co-pilot-birthday/`

## Deploy to Netlify

1. Go to [netlify.com](https://netlify.com) and sign in
2. Drag and drop this folder onto the Netlify deploy area
3. Done! You'll get a shareable URL instantly

## Share

- Use the GitHub Pages or Netlify URL
- Or zip the folder and send the `index.html` (+ `styles.css`, `script.js`) – it works offline
